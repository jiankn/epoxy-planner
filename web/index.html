epoxy-planner

Calculate resin volume from a fabrication job list. Use a small JavaScript module in a quoting tool, or export material estimates to CSV from the command line.

Install and run a batch

Install epoxy-planner v@@VERSION@@ from npm. Node.js 20 or later is required. The release archive provides the same tested package for direct installation.

npm install epoxy-planner@@@VERSION@@
npx --no-install epoxy-planner jobs.json --format csv > estimates.csv

Download an example job list with a rectangular casting, a river table and a round mold. All calculations run locally; the CLI makes no network requests.

For a visual check of the measurements and planning assumptions before you enter a batch, use the Epoxy Planner calculator.

JavaScript API

import { estimateProject, estimateBatch, estimatesToCsv } from 'epoxy-planner';

const project = {
  kind: 'rectangle', unit: 'cm',
  length: 10, width: 10, depth: 10,
  wastePercent: 10,
  price: { amount: 28, per: 'liter', currency: 'USD' }
};
const estimate = estimateProject(project);
// raw.liters = 1; recommended.liters = 1.1
const csv = estimatesToCsv(estimateBatch([project]));
FunctionContract
estimateProject(project)Returns raw and recommended liters/US gallons, total allowance percent, optional manufacturer ratio split, optional material cost and a relevant calculator URL.
estimateBatch(projects)Accepts a non-empty array and returns one result per job. Invalid input fails with its one-based job index.
estimatesToCsv(estimates)Exports one row per estimate, preserving quoted/multiline labels and neutralizing spreadsheet formulas in text cells.
usGallonsToLiters(value)
litersToUsGallons(value)		Converts finite, non-negative volume quantities using the US liquid gallon definition.

Project fields

FieldsAccepted values
kind, unitKind: rectangle, round, sphere or river. Unit is required: mm, cm or in, applying to all dimensions in a job.
DimensionsRectangle: length, width, depth. Round: diameter, depth. Sphere: diameter. River: length, depth with width or non-empty segmentWidths.
AllowanceswastePercent defaults to 10. seepagePercent and sealCoatPercent default to 0. Each allows 0–100. They are added rather than compounded.
priceOptional object: { amount: 28, per: 'liter', currency: 'USD' }. per also accepts us-gallon. Currency is a three-letter uppercase label; no exchange-rate conversion takes place.
mixRatioOptional manufacturer input: { resin: 2, hardener: 1, basis: 'volume' }. Both parts must be positive. Weight-based ratios cannot split a volume and are rejected.
nameOptional string label. Defaults to “Untitled project”.

Numeric strings, zero dimensions, negative margins, explicit null values for numeric inputs and numeric overflow are rejected. Missing price and ratio data remain null in the output. Outputs are unrounded so callers can choose display precision.

Units and planning assumptions

One US liquid gallon is exactly 3.785411784 liters. Imperial gallons are not supported. The epoxy volume unit converter provides an interactive check.

River-table width samples represent equal-length sections. For a 100 cm cavity, 2 cm depth and widths of 10 and 20 cm, raw volume is 3 liters. Adding 10% waste, 8% seepage and 5% seal allowance gives 3.69 liters. Those margins are example inputs; adjust them to the job. Check measurements in the river-table planning calculator.

Material cost uses the recommended quantity and the supplied price. It excludes labor, kit rounding, shipping and tax. The package does not infer a curing schedule, safe pour depth or universal mixing ratio; follow the selected product's manufacturer instructions.
